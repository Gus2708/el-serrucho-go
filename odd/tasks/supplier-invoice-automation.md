### T4 implementation contract

Applying another extraction is explicit, never automatic.

Scalar corrections are string/null; discounts/taxes are complete typed arrays with motives, including explicit empty arrays, never JSON strings. Manual additions require a motive. Every extracted line remains represented exactly once across the entire per-source history. Replacing extraction requires a revision motive. Unknown fields/shape fail closed; reconcile contract changes before edits.

Owner + active privileged + valid session RLS; no direct DML even service_role.
